# Geist

Locally hosted Latin variable font, weights 100–900, normal style (29,400 bytes).
Loaded through `next/font/local` with swap and a metric-adjusted fallback.

- Family: Geist, by Vercel
- Source CSS: https://fonts.googleapis.com/css2?family=Geist:wght@100..900&display=swap
- Asset: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFU.woff2
- License source: https://github.com/google/fonts/blob/main/ofl/geist/OFL.txt
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

The Latin subset is appropriate for the current English content. Add the relevant
subset if multilingual content is introduced; do not assume this file covers it.
